# SQL Business Analytics

## Project Overview

This project focuses on applying SQL to real-world business analytics requirements across Finance, Supply Chain, Sales, Customer, Product, and Market analysis.

The project uses a large business dataset and demonstrates how SQL can be used to transform raw transactional data into meaningful business insights.

## Key Areas Covered

### Finance Analytics
- Fiscal year analysis
- Customer and product-level sales analysis
- Gross sales calculations
- Monthly sales reporting
- User-defined SQL functions
- Stored procedures

### Supply Chain Analytics
- Actual vs forecast analysis
- Forecast accuracy calculation
- Net error and absolute error analysis
- Common Table Expressions (CTEs)
- Temporary tables
- Database triggers
- Database events

### Customer, Product & Market Analytics
- Top customer analysis
- Product performance analysis
- Market-level analysis
- Sales and business performance comparisons

## SQL Concepts Used
